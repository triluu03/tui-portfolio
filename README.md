# tui-portfolio

A personal terminal portfolio built with [Bubble Tea](https://github.com/charmbracelet/bubbletea) and Lip Gloss.

Access the deployed application with:

```sh
ssh triluu.dev
```

## Running locally

- Install Go to your system: https://go.dev/doc/install
- Change the `port` in `main.go` to a different one other than `22`
- Run: `go run .` at the root of the repo.
